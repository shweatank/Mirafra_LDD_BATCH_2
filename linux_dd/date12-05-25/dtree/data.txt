## 🧠 Understanding the Flow

### 1. **Device Tree (DTS)** - Hardware Description

This section:

```dts
/dts-v1/;
/ {
    compatible = "x86-generic";

    mychardev {
        label = "TechDhabaCharDevice";
        status = "okay";
    };
};
```

* Defines a node called `mychardev` in the device tree.
* Adds a property `label = "TechDhabaCharDevice";`.

The kernel module uses this node to fetch the `label` when loading.

### 2. **Kernel Module Overview**

This C code defines a kernel module with:

* A character device interface (`open`, `read`, `write`, `release`).
* Device tree parsing (`of_find_node_by_name()`).

## 📦 Compilation Steps

### Step 1: Create Makefile

```makefile
obj-m += mychardev.o

all:
	make -C /lib/modules/$(shell uname -r)/build M=$(PWD) modules

clean:
	make -C /lib/modules/$(shell uname -r)/build M=$(PWD) clean
```

### Step 2: Build the module

```bash
make
```

---

## ▶️ Loading the Module

### Step 3: Insert the module

```bash
sudo insmod mychardev.ko
```

### Output in `dmesg` (kernel logs):

```bash
dmesg | tail
```

You should see:

```
mychardev: Initializing...
mychardev: Label from DTS = TechDhabaCharDevice
mychardev: Module loaded
```

If the label isn’t printed, the device tree wasn’t applied properly.

---

## 📁 Interacting from User Space

### Step 4: Check device

```bash
ls -l /dev/mychardev
```

### Step 5: Read from the device

```bash
cat /dev/mychardev
```

Should output:

```
Hello from driver
```

### Step 6: Write to the device

```bash
echo "test" > /dev/mychardev
```

Check `dmesg` for:

```
mychardev: Received 5 bytes from user
```

---

## 🧹 Unloading the Module

### Step 7: Remove module

```bash
sudo rmmod mychardev
```

### Step 8: Check logs

```bash
dmesg | tail
```

Output:

```
mychardev: Module unloaded
```

## 🔍 Key Concepts You Learned

| Concept                  | Meaning                                       |
| ------------------------ | --------------------------------------------- |
| `register_chrdev()`      | Registers a character device with the kernel. |
| `class_create()`         | Creates a device class for `/sys/class/`.     |
| `device_create()`        | Creates `/dev/mychardev`.                     |
| `of_find_node_by_name()` | Finds the device tree node `mychardev`.       |
| `copy_to_user()`         | Sends data from kernel space to user space.   |
